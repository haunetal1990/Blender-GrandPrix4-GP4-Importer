# Blender Grand Prix 4 Importer

This plugin allows the direct import of GP4, WAD, DAT files from the classic game **Grand Prix 4** into Blender. It imports not only the 3D models but also their corresponding materials.

## Features

| Feature | Status |
|:---|:---|
| 3D Models Import (*.GP4, *.WAD)| ✅ |
| Material Import | ✅ |
| TV Cam Import | ✅ |
| *.DAT Import | ✅ |

---
